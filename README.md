# Reading Room — Ôn tập trắc nghiệm

Trang ôn tập đọc hiểu tiếng Anh chạy hoàn toàn trên trình duyệt.

Truy cập: https://anhlalyn.github.io/tracnghiem/

- 234 câu: 54 câu gốc số 147–200 và 180 câu bổ sung theo đoạn đọc.
- Giữ nguyên thứ tự câu hỏi và lựa chọn A–D.
- Chấm điểm, giải thích, đánh dấu câu, tìm kiếm và lưu tiến độ bằng localStorage.
- Không cần máy chủ ứng dụng, thư viện ngoài hoặc bước build.

## Mở cục bộ

Mở `index.html`, hoặc dùng `on-tap-trac-nghiem.html` là bản độc lập có nhúng ảnh.

## GitHub Pages

Nguồn xuất bản: nhánh `main`, thư mục `/ (root)`. File `.nojekyll` cho phép phục vụ trực tiếp các tài nguyên tĩnh. Các đường dẫn CSS, JavaScript và ảnh đều là đường dẫn tương đối, phù hợp với GitHub Pages của repository.

Kết quả học lưu trên trình duyệt và địa chỉ trang hiện tại; tiến độ của bản cục bộ không tự chuyển sang địa chỉ GitHub Pages.

## Chỉnh sửa và kiểm tra

Chạy `python build_quiz.py` để tạo lại dữ liệu; `python package_quiz.py` để tạo lại bản độc lập. Xem `HUONG-DAN.md` về nguồn câu hỏi và các ghi chú đối chiếu tài liệu.
